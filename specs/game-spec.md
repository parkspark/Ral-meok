# 뱀파이어 서바이버류 미니게임 — 최종 기획서 (MVP v1.0)

## 0. 제약 조건 (절대 위반 금지)

| 항목 | 값 |
|---|---|
| 최종 산출물 | Windows 독립 실행파일(.exe) 1개. 웹/브라우저 불가 |
| 용량 제한 | **1,474,560 bytes 이하** (실행에 필요한 파일 전체 합산) |
| 엔진/라이브러리 | 제한 없음이나, 용량 예산상 **외부 라이브러리(SDL 등) 사용 금지** — Win32 API + GDI만 사용 |
| 에셋 | 이미지/사운드 파일 사용 금지. 모든 그래픽은 GDI 도형(원/사각형)으로 절차적 렌더링 |
| 언어 | C (C99), MinGW-w64 gcc |
| 빌드 명령 | `gcc -Os -s -mwindows src/*.c -o build/game.exe` |

## 1. 장르 핵심 루프

플레이어는 화면 중앙 근처에서 이동만 하고, 공격은 자동으로 나간다.
시간이 지날수록 적이 더 많이, 더 빠르게 몰려온다. 최대한 오래 생존하는 것이 목표.

```
이동(WASD/방향키) → 가장 가까운 적에게 자동 투사체 발사
→ 적 처치 시 처치수 누적 → 처치수 임계값마다 공격력/공격속도 소폭 상승
→ 적과 접촉 시 HP 감소 → HP 0이면 게임오버 → Space로 재시작
```

## 2. 엔티티 정의

- **Player**: 위치(x,y), HP(기본 100), 이동속도, 공격쿨다운, 공격력
- **Enemy**: 위치, HP, 이동속도(플레이어 방향 추적), 접촉 데미지. 배열 기반 오브젝트 풀 사용 (동적 할당 금지 — 안정성/용량)
- **Projectile**: 위치, 방향벡터, 속도, 데미지, 수명(타임아웃)

## 3. 난이도 스케일링

- 생존시간 0~30초: 스폰 간격 1.5초
- 30~60초: 스폰 간격 1.0초, 적 이동속도 +10%
- 60초~: 스폰 간격 0.6초, 적 이동속도 +20%, 동시 최대 스폰 수 증가

(정확한 수치는 구현 중 Codex가 밸런스 조정 가능. 단, 위 3단계 구조는 유지)

## 4. UI 요소

- 좌상단: HP바 (사각형 게이지)
- 우상단: 생존시간(초), 처치수
- 게임오버 시: 화면 중앙에 "GAME OVER - 생존 XX초 - Space로 재시작" 텍스트

## 5. MVP 범위 밖 (하지 않음)

- 사운드
- 여러 무기 타입 / 무기 선택 UI
- 맵 스크롤 (고정 화면 내에서만 진행)
- 아이템 드롭
- 애니메이션 스프라이트 (도형 렌더링으로 충분)

## 6. 완료 기준 (Definition of Done)

1. `gcc -Os -s -mwindows src/*.c -o build/game.exe` 빌드 성공
2. `build/game.exe` 크기 ≤ 1,474,560 bytes
3. 실행 시 창이 뜨고 플레이어 이동/자동공격/적 스폰/충돌/게임오버/재시작이 모두 동작
4. 크래시 없이 최소 2분 이상 플레이 가능
